# OpenTherm Master Adapter

## The OpenTherm Master Adapter is development board based on the ESP32-S3. OpenTherm is a standardized protocol used between a thermostat (master) and a boiler (slave). This adapter emulates the thermostat (master) and thus acts as a replacement for the thermostat.
